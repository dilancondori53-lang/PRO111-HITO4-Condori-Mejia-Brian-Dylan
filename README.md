# Sistema de Control de Asistencia y Rendimiento de Estudiantes

## Descripción

Este proyecto fue desarrollado en Python con el objetivo de automatizar el control de asistencia y rendimiento académico de los estudiantes inscritos en un curso de capacitación.

El programa permite registrar la información de varios estudiantes, calcular su porcentaje de asistencia, determinar su condición académica según reglas establecidas y generar un resumen final con estadísticas generales del curso.

## Problema resuelto

Una academia necesita llevar el control de asistencia y calificaciones de sus estudiantes. Realizar este proceso manualmente puede generar errores y requiere más tiempo. Este programa automatiza los cálculos y la clasificación de los estudiantes, facilitando la gestión de la información.

## Requisitos para ejecutar el programa

* Tener instalado Python 3.x.
* Contar con una terminal o consola para ejecutar archivos Python.
* No se requieren librerías externas ni módulos adicionales.

## Instrucciones de ejecución

1. Descargar o clonar el repositorio.
2. Abrir una terminal en la carpeta del proyecto.
3. Ejecutar el archivo principal con el siguiente comando:

```bash
PRO111-HITO4-apellido-nombre
```

4. Ingresar los datos solicitados para cada estudiante:

   * Nombre completo.
   * Cantidad de clases programadas.
   * Cantidad de clases asistidas.
   * Calificación final.

5. Elegir si se desea registrar otro estudiante.

6. Al finalizar, el programa mostrará un resumen general de los resultados.

## Ejemplo de uso

### Entrada

Nombre completo: Juan Pérez

Clases programadas: 20

Clases asistidas: 18

Calificación final: 75

¿Desea registrar otro estudiante? N

### Salida

Nombre: Juan Pérez

Asistencia: 90.0%

Nota final: 75

Condición: APROBADO

Resumen final:

* Total de estudiantes: 1
* Aprobados: 1
* Reprobados por nota: 0
* Reprobados por asistencia: 0
* Porcentaje de aprobados: 100.0%
